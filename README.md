# 🧮 CalcNova — Scientific Calculator

A simple and user-friendly **Scientific Calculator** built using **C++**.
CalcNova is a menu-driven console application that performs basic arithmetic and scientific mathematical operations.

---

## 📌 About the Project

**CalcNova** is a beginner-friendly C++ project designed to demonstrate programming fundamentals such as variables, input/output, conditional statements, switch-case, and mathematical functions.

The calculator provides different operations through a simple menu. The user selects an operation, enters the required values, and receives the calculated result.

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Open the Project

```bash
cd CalcNova-Scientific-Calculator
```

### 3. Compile the Program

```bash
g++ main.cpp -o CalcNova
```

### 4. Run the Program

#### Windows

```bash
.\CalcNova.exe
```

#### Linux / macOS

```bash
./CalcNova
```
